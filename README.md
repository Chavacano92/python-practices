# Sistema de Monitoreo Básico

Este proyecto es un programa en Python que evalúa condiciones de temperatura, presión y humedad.

## Tecnologías
- Python

## Funcionalidad
- Detecta condiciones críticas
- Muestra alertas

## Ejemplo de uso

Ingresa la temperatura: 30  
Ingresa la presión: 0  
Ingresa la humedad: 60  

Resultado: Warning: High humidity

## Ejecución
python monitor_system.py
