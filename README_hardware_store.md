# Hardware Store System

This project is a basic inventory and pricing system for a hardware store developed in Python.

## Features
- Add new products
- Calculate sale price based on profit percentage
- Display all products
- Search products by category

## Technologies
- Python

## Example Usage

=== Hardware Store System ===  
1. Add product  
2. Show products  
3. Search by category  
4. Exit  

Choose an option: 1  

Enter product name: Drill  
Enter category: Tools  
Enter cost price: 100  
Enter profit percentage: 30  

Product added successfully.

## How to Run

python hardware_store.py
